🔑 Configuration Supabase Obligatoire

Entrez vos clés Supabase pour que les données soient partagées entre tous vos appareils (PC, mobile, tablette) en temps réel.

Ces clés sont stockées uniquement dans votre navigateur. La clé anon est publique et sécurisée par les règles RLS de Supabase.

🗄️ Créer les tables Supabase (à faire une seule fois)

Dans votre projet Supabase, allez dans SQL Editor et exécutez ce script : 

-- Table invités
create table if not exists guests (
  id uuid default gen_random_uuid() primary key,
  created_at timestamptz default now(),
  prenom text,
  nom text,
  genre text default '',
  type text default '',
  presence text default 'pending',
  cote text default '',
  via_lien boolean default false,
  validated boolean default false
);

-- Table programme
create table if not exists events (
  id uuid default gen_random_uuid() primary key,
  created_at timestamptz default now(),
  heure text,
  titre text,
  description text default ''
);

-- Accès public en lecture/écriture (pour les invités)
alter table guests enable row level security;
alter table events enable row level security;

-- Si la table guests existe déjà, ajoutez la colonne validated :
-- alter table guests add column if not exists validated boolean default false;

create policy "public read guests" on guests for select using (true);
create policy "public insert guests" on guests for insert with check (true);
create policy "public update guests" on guests for update using (true);
create policy "public delete guests" on guests for delete using (true);

create policy "public read events" on events for select using (true);
create policy "public insert events" on events for insert with check (true);
create policy "public delete events" on events for delete using (true);

📋 Comment déployer sur GitHub Pages (vous avez déjà un repo)

1
Assurez-vous que les deux fichiers sont dans votre repo : index.html (page invités) et admin.html (cette page).
2
Sur GitHub, allez dans Settings de votre repo → section Pages.
3
Sous Branch, choisissez main (ou master) et le dossier / (root), puis cliquez Save.
4
Après ~1 minute, votre URL sera : https://VOTRE-USERNAME.github.io/NOM-REPO/
5
Partagez le lien index.html aux invités et gardez admin.html pour vous.

⚠️ Important : Les données sont stockées dans le localStorage du navigateur. Cela signifie que les réponses des invités sont sauvegardées sur leur appareil, pas sur le vôtre. Pour voir toutes les réponses centralisées, utilisez la fonction Exporter JSON depuis la page invité ou passez à une base de données (Supabase, Firebase) — contactez un développeur si besoin.

🔗 Lien de la page invités

Une fois déployé sur GitHub Pages, votre lien invité sera :

https://VOTRE-USERNAME.github.io/NOM-REPO/

Modifiez manuellement ce lien ci-dessus si votre URL GitHub Pages est différente. La page index.html et la page admin.html partagent les mêmes données via le localStorage — elles doivent être sur le même domaine.
